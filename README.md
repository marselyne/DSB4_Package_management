# Financial Data Parser

Проект по получению и анализу финансовых данных компаний с использованием Python и автоматического тестирования.

## 📌 О проекте

В рамках проекта реализован инструмент для получения финансовой информации о компаниях по ticker symbol.

Проект включает:
- обработку financial data
- работу с ticker symbols
- поиск финансовых показателей
- обработку ошибок
- unit testing

Реализована функция получения:

- данных по ticker symbol
